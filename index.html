    About

    Three everyday tools for your own office files. Works offline once installed. Nothing you choose leaves your device — every file is processed inside the app.

    • Excel: removes sheet, workbook and read-only / modify protection from .xlsx / .xlsm / .xls files.
    • PDF Unlock: removes copy / print / edit restrictions, or the open password if you know it.
    • PDF Lock: adds an open password (AES-256) and can block print / copy / edit.

    The original file is never changed — a new file is saved for you to download. A file that asks for a password when opening can only be unlocked with that password.

    Please use this only on files you own or have permission to modify.
